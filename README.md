# PAYMEX — статическая вёрстка (без бэкенда)

Сборка фронтенда для верстальщика: только HTML/CSS/JS, API не требуется для просмотра главной и навигации.

## Быстрый просмотр

### Вариант 1 — встроенный preview-сервер (рекомендуется)

Нужен Node.js 18+:

```bash
node preview-server.mjs
```

Откройте в браузере: **http://127.0.0.1:8765/**

Сервер отдаёт статику и подставляет заглушки для `/api/*` (курсы, пустая история).

### Вариант 2 — любой статический сервер

```bash
npx --yes serve -l 8765 .
```

Курсы на главной подтянутся из дефолтов в коде, если `/api/exchange-rate` недоступен.

**Не открывайте `index.html` двойным кликом** (`file://`) — ES-модули не загрузятся.

## Содержимое

| Файл / папка | Назначение |
|--------------|------------|
| `index.html` | Точка входа |
| `style.css` | Базовые стили |
| `paymex-theme.css` | Тема PAYMEX (градиенты, карточки, кнопки) |
| `assets/` | Собранный JS (React) |
| `vendor/` | Доп. скрипты |
| `icons.svg`, `favicon.svg` | Иконки |

## Что работает без API

- Главная: обмен, курсы (мок или дефолт), сетка сервисов, нижнее меню
- Модальные окна (UI), переходы по вкладкам
- Профиль, поддержка (статический UI)

## Что не работает без бэкенда

- Отправка заявок, создание ордеров, UniUni-каталог, реальные курсы с сервера
- Авторизация Telegram (`initData`)
